# HTL-ReID Visual Analysis

This directory contains the inference-only visual analyses for the frozen
RGBNT201 paper model:

- `fig_hs_selection.png`: staged HS saliency and frequency token selection.
- `fig_aci_routing.png`: three-stage ACI cross-modal routing weights.
- `fig_dhf_gating.png`: sample-adaptive and mean DHF seven-route weights.
- `fig_dhf_activation.png`: DHF route activation maps.
- `fig_tsne_baseline_full.png`: Backbone versus full-model t-SNE.
- `fig_ranklist_baseline_full.png`: Backbone versus full-model retrieval lists.

The figures are generated by `tools/generate_paper_visualizations.py` without
retraining. The baseline uses E049 `HTL-ReID_best.pth`. The full model uses the
E043 epoch-31 `HTL-ReID_best_rank1.pth` checkpoint with the frozen E045
inference setting: flip alpha 0.9 and ACI/CLS/PLR/DHF weights
1.0/1.1/0/1.58, with re-ranking disabled. Exact metrics and routing arrays are
stored in `summary.json` and `routing_statistics.npz`.

The overall model architecture diagram is maintained separately because it is
a vector illustration rather than an inference result.
