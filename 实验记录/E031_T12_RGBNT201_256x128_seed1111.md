# E031｜RGBNT201 T12迁移到256×128

- 状态：计划中
- 登记时间：2026-08-27 15:34 CST
- 对应论文实验：T12-R256
- 实验目的：验证T12在论文采用的256×128与论文对齐优化协议下能够正常训练，并建立第一个新协议结果；同时记录显存、耗时和精度，为后续同协议重跑M0/K1及必要消融提供依据。
- 相对历史E029的协议变化：输入由384×192改为256×128；为保持固定K=1，`SFTS_RATIO`由`1/288`换算为`1/128`；优化协议由20-epoch诊断设置改为参照非CLIP共享ViT DeMo*官方代码的Adam、batch 64、50 epoch、10-epoch warm-up、3.5e-4新模块LR与2.8e-4 ImageNet ViT backbone LR。因此本实验不是单变量分辨率消融，不能将指标变化只归因于输入尺寸。
- 配置：`configs/RGBNT201/paper/base.yml` + `configs/RGBNT201/fusion/t12_sfts_k1_shared_token_recon.yml`
- 数据集与协议：RGBNT201 `train_171`训练、`test`评估；三模态联合评估；每个epoch验证；关闭re-ranking。
- Seed / batch / epoch：1111 / 64 / 50
- 输入尺寸：256×128；ViT stride 16×16，共128个patch；每身份实例数8。
- Optimizer / LR / weight decay：Adam / 3.5e-4 / 1e-4；ImageNet ViT backbone LR为2.8e-4，factor为0.8。5e-6只属于DeMo官方代码的CLIP视觉编码器分支，本实验不采用。
- Scheduler / warm-up：50 epoch完整cosine horizon；前10 epoch从0.1倍LR线性warm-up。scheduler按epoch步进，避免把论文中的10-epoch warm-up误当作10 iterations。
- 模型设置：共享ViT-B/16；固定K=1 SFTS共享mask；三轮FACR；训练期共享跨模态token重建，hidden dim 256、损失系数0.1、前5 epoch auxiliary warm-up；re-ranking关闭。
- 数据增强与损失：仅使用外部对照共有的水平翻转、padding/crop和random erasing；关闭项目自定义灰度块替换及modality dropout。Label-smoothed CE与soft-margin Triplet保持1:1，T12重建损失设置不变。
